# SEO & Web Performance

Используй этот навык перед публикацией сайта и при аудите существующего проекта.

## Technical SEO

Проверь:

- уникальный `<title>`;
- meta description;
- canonical;
- Open Graph;
- Twitter cards при необходимости;
- правильную структуру H1-H6;
- semantic HTML;
- sitemap.xml;
- robots.txt;
- index/noindex;
- понятные URL;
- redirects;
- 404;
- hreflang для мультиязычных сайтов;
- structured data/schema.org там, где это уместно.

## Core Web Vitals

Оцени риски для:
- LCP;
- INP;
- CLS.

Ищи:
- тяжелые hero-изображения;
- font blocking;
- layout shift;
- лишний JavaScript;
- длинные main-thread tasks;
- неэффективные third-party scripts.

## Изображения

- современные форматы;
- width/height;
- responsive sizes;
- lazy loading ниже первого экрана;
- preload только для действительно критичных ресурсов.

## Контент

Не набивай текст ключевыми словами.
SEO-текст должен оставаться естественным и полезным.

## Результат

Выдай:
- обязательные исправления до релиза;
- важные улучшения;
- необязательные оптимизации;
- чек-лист повторной проверки.
