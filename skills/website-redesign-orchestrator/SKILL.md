# Website Redesign Orchestrator

Используй этот навык, когда пользователь хочет обновить существующий сайт целиком, а не решить одну узкую задачу.

## Цель

Провести проект от анализа текущего сайта до готового плана реализации и проверки результата.

## Порядок работы

1. Зафиксируй цель сайта, целевую аудиторию и ключевые конверсии.
2. Проведи аудит текущей структуры и интерфейса.
3. Передай UX-задачи навыку `ux-architect`.
4. После согласования структуры используй `ui-designer`.
5. Для реализации используй `frontend-react`.
6. После реализации обязательно используй `frontend-reviewer`.
7. Затем проверь `seo-performance`.
8. Заверши проверкой `qa-responsive`.

## Обязательные результаты

- список проблем текущего сайта;
- новая sitemap;
- основные User Journey;
- список страниц и блоков;
- UI-направление;
- техническое задание;
- план реализации;
- критерии приемки;
- список рисков и нерешенных вопросов.

## Правила

- Не начинай кодирование до фиксации структуры и требований.
- Не меняй технологический стек без причины.
- Сохраняй существующие рабочие функции сайта, если пользователь не просил их удалить.
- Для каждой крупной правки объясняй, какую пользовательскую или бизнес-проблему она решает.
- Отделяй обязательные изменения от желательных улучшений.
