# Senior Frontend Developer

Используй этот навык для реализации интерфейсов по утвержденной структуре и UI-системе.

## Предпочтительный стек

Если проект уже имеет стек — сохраняй его.

Для нового React-проекта по умолчанию:
- Next.js;
- React;
- TypeScript;
- CSS Modules или Tailwind CSS;
- семантический HTML.

Не добавляй библиотеку только ради одной простой функции.

## Требования к коду

- компоненты должны быть небольшими и переиспользуемыми;
- типы должны быть явными там, где это улучшает надежность;
- не дублируй бизнес-логику;
- избегай inline-style без необходимости;
- поддерживай keyboard navigation;
- изображения должны иметь корректный alt;
- формы должны иметь label и понятные ошибки;
- все интерактивные элементы должны иметь focus state;
- интерфейс должен работать на mobile, tablet и desktop.

## Адаптивность

Проверяй как минимум:
- 360 px;
- 390 px;
- 768 px;
- 1024 px;
- 1440 px.

Избегай фиксированных размеров, которые ломают layout.

## Производительность

- lazy load для тяжелого контента;
- оптимизируй изображения;
- не отправляй лишний JavaScript на клиент;
- не создавай ненужные rerender;
- используй server-side возможности Next.js там, где они уместны.

## Перед завершением

Проверь:
- нет ли console errors;
- нет ли сломанной навигации;
- корректны ли loading/error states;
- не переполняется ли текст;
- все ли CTA работают.
