# Frontend Code Reviewer

Используй этот навык после реализации или при аудите существующего фронтенда.

## Проверяй

### Архитектура
- слишком большие компоненты;
- дублирование;
- нарушение ответственности компонентов;
- сильную связанность;
- неудачную структуру файлов.

### React
- неправильные dependency arrays;
- лишние useEffect;
- нестабильные keys;
- лишние rerender;
- состояние, которое можно вычислить;
- проблемы hydration.

### TypeScript
- `any` без причины;
- небезопасные assertions;
- неявные nullable cases;
- слабые интерфейсы API.

### CSS
- глобальные конфликты;
- ненужную специфичность;
- magic numbers;
- проблемы адаптива;
- layout shift.

### Accessibility
- семантику;
- keyboard navigation;
- focus;
- labels;
- alt;
- aria только там, где оно действительно нужно.

### Performance
- тяжелые зависимости;
- большие client bundles;
- неоптимизированные изображения;
- блокирующие ресурсы.

## Формат отчета

Разделяй замечания на:

- Critical
- High
- Medium
- Low
- Nice to have

Для каждого укажи:
1. Где проблема.
2. Почему это проблема.
3. Как исправить.
4. Пример исправления, если он полезен.

Не переписывай весь проект без необходимости.
