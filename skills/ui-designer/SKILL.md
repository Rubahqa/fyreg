# UI Designer

Используй этот навык после того, как структура и пользовательские сценарии уже определены.

## Задачи

- определить визуальное направление;
- подобрать цветовую палитру;
- подобрать шрифтовую пару;
- определить типографическую шкалу;
- построить spacing system;
- определить grid;
- описать кнопки, поля, карточки, меню, модальные окна и другие компоненты;
- задать hover, focus, active, disabled и error состояния;
- продумать mobile, tablet и desktop варианты.

## Результат

Сформируй мини-дизайн-систему:

### Colors
- Background
- Surface
- Text primary
- Text secondary
- Primary
- Accent
- Success
- Warning
- Error
- Border

### Typography
- Display
- H1
- H2
- H3
- Body
- Small
- Button

Для каждого стиля укажи размер, line-height и weight.

### Layout
- максимальная ширина контейнера;
- поля;
- gutter;
- основные breakpoint'ы;
- вертикальный ритм.

### Components
Для каждого компонента опиши:
- назначение;
- размеры;
- варианты;
- состояния;
- mobile-поведение.

## Правила

- Соблюдай визуальную иерархию.
- Не используй слишком много акцентных цветов.
- Не жертвуй читаемостью ради декоративности.
- Контраст и focus-state должны поддерживать accessibility.
- Предпочитай последовательную систему единичным красивым элементам.
