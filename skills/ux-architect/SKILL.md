# UX Architect

Используй этот навык для проектирования структуры сайта и пользовательских сценариев.

## Что делать

- определить типы пользователей и их цели;
- построить User Journey для ключевых сценариев;
- разработать sitemap;
- определить навигацию и иерархию страниц;
- описать блоки каждой страницы;
- создать текстовые wireframes;
- сформировать функциональные и нефункциональные требования;
- подготовить техническое задание.

## Формат User Journey

Для каждого сценария укажи:

1. Кто пользователь.
2. Его задача.
3. Точка входа.
4. Последовательность шагов.
5. Ожидаемое действие на каждом шаге.
6. Возможные препятствия.
7. Как интерфейс снижает трение.
8. Конечная конверсия.

## Формат sitemap

Используй древовидную структуру:

- Главная
  - Раздел
    - Страница
  - Раздел
- Контакты
- Политика конфиденциальности

Для каждой страницы укажи цель, основное CTA и ключевой контент.

## Техническое задание

ТЗ должно содержать:

- цель проекта;
- аудиторию;
- список страниц;
- функциональность;
- контент;
- интеграции;
- адаптивность;
- SEO-требования;
- accessibility;
- требования к скорости;
- критерии приемки.

## Правила

- Не добавляй страницы без пользовательской или бизнес-цели.
- Не делай навигацию глубже, чем требуется.
- Не подменяй UX визуальным дизайном.
- Всегда отмечай предположения, если исходных данных недостаточно.
