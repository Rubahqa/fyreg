# ChatGPT Website Redesign Skills

Набор навыков для полного обновления сайта через ChatGPT/Codex.

## Состав

- `website-redesign-orchestrator` — координация всего редизайна
- `ux-architect` — User Journey, sitemap, wireframes, ТЗ
- `ui-designer` — визуальная система и компоненты
- `frontend-react` — HTML/CSS/JS/React/Next.js/TypeScript
- `frontend-reviewer` — code review
- `seo-performance` — SEO и Core Web Vitals
- `qa-responsive` — адаптивность и QA

## Рекомендуемый порядок

1. website-redesign-orchestrator
2. ux-architect
3. ui-designer
4. frontend-react
5. frontend-reviewer
6. seo-performance
7. qa-responsive

## Установка

1. Создайте новый публичный или доступный вашему приложению GitHub-репозиторий.
2. Загрузите в него содержимое этой папки.
3. Скопируйте URL репозитория, например:
   `https://github.com/USERNAME/chatgpt-website-redesign-skills`
4. В настройках приложения в разделе **«Навыки (skills с GitHub)»** вставьте URL и нажмите **«Установить»**.

## Если приложение ожидает один SKILL.md

Некоторые загрузчики skills умеют устанавливать только один навык из одного репозитория. В этом случае:
- создайте отдельный GitHub-репозиторий для каждой папки из `skills/`; или
- начните только с `website-redesign-orchestrator`, а остальные добавьте позже.

## Как использовать

Пример запроса:

> Проведи полный редизайн моего сайта. Сначала проанализируй текущую структуру и UX. Не пиши код, пока не подготовишь sitemap, User Journey, список страниц и ТЗ. После этого предложи UI-систему и только затем переходи к реализации.

## Важно

Формат skills у разных приложений может немного отличаться. В этом наборе используется распространенный формат `SKILL.md` с YAML frontmatter (`name`, `description`) и Markdown-инструкциями.
